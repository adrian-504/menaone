How to get a client ID and tenant ID (one-time setup, about 2 minutes)
  1. Go to portal.azure.com and open Microsoft Entra ID → App registrations → New registration.
  2. Name it "MENA BIG Workspace". Under Supported account types, choose "Accounts in this organizational directory only" (or "Any organizational directory" if you want to sign in with other tenants too).
  3. Under Redirect URI, select platform "Mobile and desktop applications" and add exactly: http://localhost:18473/callback
  4. Click Register. On the Overview page, copy the Application (client) ID into the field above, and the Directory (tenant) ID into the Tenant ID field above. Both are required — a single-tenant app registration (the default) will fail sign-in without the Tenant ID.
  5. Go to Authentication in the left menu and make sure "Allow public client flows" is set to Yes, then Save.
  6. Go to API permissions → Add a permission → Microsoft Graph → Delegated permissions and add: Mail.ReadWrite, Calendars.ReadWrite, User.Read, offline_access.
  7. Click Save above, then Connect.

Data

Company Master Data

Links every legacy company name on Proposals, Contacts, Agreements and Projects to a canonical Company record, and moves researched industries onto the new controlled taxonomy. Backs up your database first, never guesses on an ambiguous name (those go to a Needs Review queue on the Companies page instead), and is safe to run more than once — it only processes what's still unlinked.

Data Backup

A backup file is a complete copy of everything in MENA One — companies, opportunities, meetings, projects, proposals, tasks, notes, commitments and settings. Restore reads these files and older .json backups too. The file includes client correspondence (cached Outlook mail and meetings) — keep it in the MENA BIG OneDrive only.
